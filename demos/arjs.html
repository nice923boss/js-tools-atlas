運作方式

AR.js 用 ARToolKit（WebAssembly）在每一格畫面找出黑色方框，比對框內圖樣確認是 Hiro，再依相機參數解出標記相對鏡頭的姿態矩陣，three.js 用同一組投影矩陣把物件畫在標記上。「模擬畫面」是用 three.js 即時算繪桌上的標記，同樣交給 AR.js 辨識。

// AR.js 3.4.8 + three.js
const ctx = new ArToolkitContext({
  cameraParametersUrl: "camera_para.dat" })
ctx.init(() => camera.projectionMatrix
  .copy(ctx.getProjectionMatrix()))
new ArMarkerControls(ctx, markerRoot, {
  type: "pattern", patternUrl: "patt.hiro" })
// every frame
ctx.update(frameCanvas)
